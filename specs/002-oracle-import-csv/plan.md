# Implementation Plan: Generate the import CSV from the pipeline

**Branch**: `002-oracle-import-csv` | **Date**: 2026-11-11 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/002-oracle-import-csv/spec.md`

## Summary

A new command of the ISSTA 2027 pipeline, `python -m issta_tcm oracle-import`, generates
`inputs/oracle/veredito_<system>.csv` with one row per edit of `s3_diff/edits.csv`, in the columns
of Appendix D of spec 001. The complete use case texts come from the same context that the
labeling sheet and the techniques already use (field `context` of
`s5_blind/public/requests_T1.jsonl`, generated by `claret.render(..., mark=...)`), split into the
previous and the modified version. The version labels come from the system configuration (`v1.1`,
`v1.2`). Before writing, the command validates each row with the Veredito import rules (FR-052 and
FR-053 of 001), shows a summary and fails if any row would be refused. Values are copied in the
language in which they were captured; the S5 notice for a missing use case is kept as is.

## Technical Context

**Language/Version**: Python >= 3.10 (that of the `issta-tcm` package; on the researcher's machine,
`C:\Users\diego\AppData\Local\Python\bin\python.exe`)

**Primary Dependencies**: only the standard library (`csv`, `collections`, `dataclasses`) and
modules of the package itself (`config`, `stages.common`, `evaluation.oracle`, `utils`); no new
dependency

**Storage**: files; reads `runs/<run>/s3_diff/edits.csv`, `s5_blind/public/requests_T1.jsonl` and
`s5_blind/_private/edits_index.json`; writes `inputs/oracle/veredito_<system>.csv`

**Testing**: pytest (`src/tests/`), in the same style as `test_oracle.py` (`tmp_path` and
`monkeypatch`)

**Target Platform**: researcher's machine (Windows), command line

**Project Type**: CLI subcommand of an existing Python package

**Performance Goals**: Minitest (38 edits) in less than 1 minute (SC-001); in practice, about
1.2 seconds

**Constraints**: deterministic output (FR-007); UTF-8 without BOM, RFC 4180 (`csv` with `\r\n`
between records and `\n` inside quoted fields); no labels, technique outputs or blind ids (FR-008);
code, comments and command messages in English (the command is a researcher tool, not part of the
localized Veredito UI)

**Scale/Scope**: a few hundred edits per system; each complete use case currently has up to about
2,200 characters (Veredito limit: 40,000)
